# Interface sound samples

Source: https://auge-xp.com/assets/sounds/ — retrieved 2026-10-06 for the requested AUGE XP sound replication.
These are the original reference audio files, not synthesized approximations. No license was supplied with the files; this attribution does not grant a redistribution license.

- `hover-1…4.mp3`: randomized hover variants, no consecutive repeat.
- `click.mp3`: buttons and links.
- `menu-open.mp3`: opening navigation.
- `transition.mp3`: project transition curtain, delayed 120 ms.
- `step-1…6.mp3`: gallery selection steps.
- `scramble.mp3`: reference curtain-title scramble; retained for future use (our curtain has no title).

Playback uses Web Audio with 0.6 master gain and trims leading silence at the reference threshold (0.0025). First interaction unlocks audio; the sound toggle persists the visitor's choice. Hidden pages stop playback. No background music or external audio requests.
