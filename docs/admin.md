# 个人内容后台

开发服务启动后访问 `/admin`。项目和底部横向素材分成两个标签页，原有内容自动导入。

- 新建项目 → 上传封面 → 填写名称和详情 → 批量上传详情图片或视频 → 保存修改。
- 项目列表的上下箭头调整首页顺序；大小可选择原始排版、小、大；可从首页隐藏。
- 底部画廊自动同步首页展示的项目封面；独立素材支持批量上传、替换、上下调整顺序，以及 50%–150% 大小，无需关联项目。删除项目不会移除独立素材。
- 项目内「详情素材」支持批量上传图片和视频，混合排序、预览及移除；保存后在详情页按原始比例展示，视频无控件、静音自动循环播放。视频支持 MP4、WebM、MOV，原文件不超过 200MB；上传前在浏览器内自动压缩为 WebM（VP8、CRF 10、目标码率 4Mbps、最高 1920×1080、不放大原视频、移除音轨），压缩结果不超过 30MB。处理期间显示阶段、压缩进度和前后体积，可随时取消。批量上传中途失败时，已完成的素材仍保留在待保存列表。
- 「悬停视频」用于首页悬停播放，独立于详情视频；静态封面用于项目列表和下一项目。
- 所有编辑统一点击「保存修改」生效，离开页面会提醒未保存的修改。
- 每个项目的「详情页颜色」可独立设置背景色、文字色和辅助文字色，支持取色器、HEX 色值、即时预览和恢复默认。保存后应用于详情页导航、正文及底部项目列表；分隔线跟随文字色。未配置的项目保持默认白底黑字。
- Portfolio V1 是独立交互页面，保留原行为，普通详情字段不改变该页面。

## 存储和部署

本机开发内容保存至 `data/content.json`，文件位于 `data/uploads/`；这两处已纳入 Git。Cloudflare 线上内容独立保存在 `zzmax-content` R2 存储桶，通过 `CONTENT_BUCKET` 读取，上传文件通过 `/media/文件名` 提供。运行 `npm run deploy:cloudflare` 会依次检查版本、构建、部署代码和静态文件，再自动将本地最新内容同步到线上；每次部署均以本地内容为准。

线上编辑请访问 `https://zzmax.icu/admin`，点击「保存修改」后直接写入 R2，不需要重新部署。首页和项目详情按请求读取内容；同一浏览器中已打开的页面会接收保存通知并刷新，其他设备可刷新页面获取最新内容。本地后台只修改本地数据。

只更新内容、不部署代码时，运行 `npm run sync:content -- --publish`；不加 `--publish` 只比较并备份。命令会先备份线上配置、校验素材、补传缺失文件，最后更新配置并读回确认。已有线上素材保留，备份位于 `output/cloudflare/content-sync-*/`。同步期间不要在两边后台编辑；若发布前发现内容变动，命令会停止，需重新比较。新增 `public/assets` 文件时使用完整部署命令，它会先发布静态文件再同步内容。若内容同步失败，已完成的代码部署不会自动回滚，修复问题后可单独重试同步。线上后台的独有编辑需先带回本地，否则下次部署会以本地版本覆盖。更多部署步骤及依赖版本要求见 `CLOUDFLARE.md`。

删除素材引用并保存后，后台会清理不再引用的上传文件；备份应同时保留内容配置和素材。自托管 Node.js 时可通过 `CONTENT_DIR` 指定持久目录；Cloudflare 部署使用 R2，无需持久磁盘。

本机开发的 localhost 无需密码。线上必须配置 `ADMIN_PASSWORD`（建议随机长密码），否则后台拒绝访问。设置到 `.env.local` 或服务器环境后重启服务。浏览器原生登录弹窗的用户名任意填写，密码为配置值。线上使用 HTTPS。

```dotenv
ADMIN_PASSWORD=替换成你的随机长密码
# 自托管时可设置持久卷路径
# CONTENT_DIR=/var/lib/jimmy-portfolio
```

后台入口及写入接口均有鉴权检查，写入校验同源 Origin，单文件限制 30MB。上传支持 JPG、PNG、WebP、GIF、AVIF、MP4、WebM、MOV。多标签页同时编辑时，最后保存的版本覆盖前一个版本。

## 视频压缩

首次上传视频会下载约 32MB 的本地托管转码引擎，后续可使用浏览器缓存。转换在 Web Worker 中运行，不依赖服务器安装 FFmpeg；MOV 由转码引擎解码，不要求浏览器原生支持。处理耗时取决于视频长度、分辨率和电脑性能，15 分钟超时会提示重试；不支持的编码会明确报错。压缩优先保证清晰度，不能保证所有视频都比原文件小；超过输出限制会提示裁短，不会强制降低画质。

`npm run dev` 和 `npm run build` 前会自动运行 `prepare:video`，从锁定的 FFmpeg npm 包生成引擎静态文件。WASM 分为两个小于 25MiB 的文件，兼容现有静态资源托管限制；不要手动修改生成目录。
