# 个人内容后台

开发服务启动后访问 `/admin`。项目和底部横向素材分成两个标签页，原有内容自动导入。

- 新建项目 → 上传封面 → 填写名称和详情 → 批量上传详情图片 → 保存修改。
- 项目列表的上下箭头调整首页顺序；大小可选择原始排版、小、大；可从首页隐藏。
- 横向素材支持批量上传、替换、上下调整顺序、设置关联项目，以及 50%–150% 大小。
- 视频请上传到「悬停视频」或底部素材；静态封面用于项目列表和下一项目。
- 所有编辑统一点击「保存修改」生效，离开页面会提醒未保存的修改。
- Portfolio V1 是独立交互页面，保留原行为，普通详情字段不改变该页面。

## 存储和部署

内容保存至 `data/content.json`，文件位于 `data/uploads/`。上传文件通过 `/media/文件名` 提供；支持运行中的生产服务新增文件。备份整个 `data` 目录即可。目录已加入 Git 忽略，避免上传素材误入代码仓库。删除内容仅解除引用，不删除原文件。

这版使用 Node.js + 持久磁盘，适合本机或单实例自托管服务器。部署时将 `CONTENT_DIR` 设置为持久卷的绝对路径；不要使用临时文件系统或无持久磁盘的 serverless 部署（如默认 Vercel）。多实例部署或云端托管需先改接数据库与对象存储。

本机开发的 localhost 无需密码。线上必须配置 `ADMIN_PASSWORD`（建议随机长密码），否则后台拒绝访问。设置到 `.env.local` 或服务器环境后重启服务。浏览器原生登录弹窗的用户名任意填写，密码为配置值。线上使用 HTTPS。

```dotenv
ADMIN_PASSWORD=替换成你的随机长密码
# 自托管时可设置持久卷路径
# CONTENT_DIR=/var/lib/jimmy-portfolio
```

后台入口及写入接口均有鉴权检查，写入校验同源 Origin，单文件限制 30MB。上传支持 JPG、PNG、WebP、GIF、AVIF、MP4、WebM、MOV。多标签页同时编辑时，最后保存的版本覆盖前一个版本。
