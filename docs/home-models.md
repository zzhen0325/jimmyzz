# 首页 GLB 模型

首页实体和图片平面统一从 GLB 加载。已有雕塑、传送枪和天体继续使用原 GLB；其余模型由 `scripts/prepare-home-geometry.mjs` 在开发启动或生产构建前生成，输出到 `public/assets/models/home-prepared/`。

当前输出 16 个文件：银色 ZZ Logo、Jimmy 字标、吃面人物、好运罐、玻璃三角形、漩涡承载平面、9 个透明图片平面，以及配置中暂时隐藏的滑板人物。图片平面保留原来的朝向镜头行为和透明边缘。

## 更新素材

修改 `src/lib/home-3d-config.ts`、几何源文件或 `public/assets/images/floating/` 中的源图后，运行：

```sh
npm run prepare:home-geometry
```

`npm run dev` 和 `npm run build` 会自动执行。开发服务器已运行时需手动执行并刷新页面。输入指纹没有变化时跳过生成。

生成过程使用无损 Meshopt 压缩，不精简网格、不量化顶点、不缩小贴图。脚本重新读取每个 GLB，校验位置、法线、UV、自定义玻璃边缘属性、索引、变换和材质值；内嵌 PNG 在转换 glTF 贴图方向后进行逐像素校验。玻璃高度图以原有半浮点数据嵌入 GLB。

GLB 保存模型和贴图，运行时继续设置可调材质、物理运动、玻璃折射和漩涡着色器。天空、雨和屏幕后期处理属于实时渲染效果。

## 开场与滚动

首次进入显示 11 帧 ZZ loading，等待场景和着色器就绪，并至少完整播放一次后淡出。减少动态效果模式显示静态帧。模型加载失败时退出 loading 并显示错误提示；返回首页时复用已有场景，不重复播放 loading。

滚动弯曲改由共享 WebGL 网格渲染，保留原曲线并避免重复应用 SVG 位移滤镜。滚动停止后恢复原生媒体显示；纹理缓存和画布面积均有限制。实现及前后性能对比见 `docs/scroll-bend.md`。
